# Hexspin

六角形のタイルを 3 枚ずつ回して、同じ色の三角形を作って消すパズル。

- タイル 3 枚が接する頂点を選び、3 枚を 120° ずつ回す。揃うまで最大 3 回回り、
  1 周しても揃わなければ元に戻る（空振り）
- 互いに隣り合う同じ色の 3 枚（三角形）が消える。周りの 6 枚を同じ色で囲むと
  フラワーになり、外周の 6 枚が消えて大きなボーナスが付く
- 消えたら上のタイルが落ちて補充される。連鎖するほど得点の倍率が上がる
- エンドレス。どこを回しても揃わなくなったら終わり
- ベストスコアは localStorage の `hexspin:best` に残す

操作は、マウスならクリックで時計回り・右クリックで反時計回り。タッチは 1 回目で頂点を
選び、もう一度タップするかボタンで回す。押した位置に一番近い頂点を軸にするので、
小さな点を狙わなくてよい。

## 盤面の持ち方

頂点が左右を向いた六角形を縦の列に積み、奇数列を半マス下げて敷き詰める。
列の中ではタイルがまっすぐ縦に並ぶので、落下は列ごとに閉じる。そのため盤面は
`board[列][段]` の列優先で持つ。

回転の単位になる 3 枚の組は、座標の場合分けを手で書かず、隣接関係から総当たりで
列挙している（`TRIANGLES`）。

ルールは `lib/game.ts` に React から切り離して書いてあり、`lib/game.test.ts` で確かめている。
