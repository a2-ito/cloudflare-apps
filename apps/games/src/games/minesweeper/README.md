# マインスイーパー

数字（周りの 8 マスにある地雷の数）を手がかりに、地雷以外のマスをすべて開けるパズル。

- 初級 9×9・地雷 10 個 / 中級 16×16・地雷 40 個
- 1 手目で開いたマスとその周りには地雷を置かないので、最初の一手で負けることはない
- 旗はパソコンなら右クリック、スマホなら長押しか「旗モード」で立てる
- 開いた数字をもう一度押すと、旗の数が合っていれば周りをまとめて開く
- レベルごとのベストタイムは localStorage の `minesweeper:best:<level>` に残す

ルールは `lib/game.ts` に React から切り離して書いてある。
